# Clapper 0.4.0 — local narration

- Optional local Kokoro narration: six US/UK English voices, with explicit `clapper voices install` and voice auditions. Speech models and inference dependencies are not bundled in the default runtime.
- Dedicated narrator, cue and script models, plus `NarrationAudio` for whole-script or scene-local playback. Preview, render, still, review and cue inspection prepare configured narration.
- A committed cast lock pins model/runtime identity, voice embeddings and speaking speed. Per-cue voice overrides are rejected, unchanged takes reuse identical cached audio, and overflowing or oversized speech fails instead of silently truncating.
- Updated Clapper skill covers installation, auditioning, voice consistency and narration timing. Technical explainers now establish intuition and complete end-to-end flows before descending into architecture and calculus.
- Added editable Firstmate and Universal Transformers film projects with research and verification notes. Exported videos remain local build outputs.
- Release acceptance now exercises the optional speech download and real narration export using the managed Node/npm toolchain, and verifies that narration/explainer skill references ship in the runtime.

## Install or update

```sh
npx --yes @archastro/clapper@0.4.0 --version
npx skills add ArchAstro/clapper --skill clapper --global
```

The qualified native release target is macOS Apple Silicon. The skill is available in this tag under `skills/clapper` and inside the matching runtime archive. Existing projects retain their runtime pins; narration requires the 0.4.0 runtime.

See [narration setup](../narration.md) for the authoring API and workflow.
